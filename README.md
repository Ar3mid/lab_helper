Инструкция:

установка зависимостей: pip install -r requirements.txt

запуск: python app.py

Использование:
запустить, ввести два массива данных. вводить дробные числа в виде десятичной дроби (разделитель в дробном числе не важен)
расчет таблицы МНК будет работать при наличии 3 и более точек, иначе будет ошибка.
построить график можно только при наличии таблицы МНК.
На графике находятся точки экспериментальных данных и линия тренда (аппроксимирующая прямая, показывающая линейную зависимость), оси можно переименовать вручную, нажав соответствующую кнопку.
сохраняется график в директорию с загрузками в формате .png, в случае если она недоступна, то в домашнюю папку пользователя.

все ошибки показаны в журнале расчетов (консоли/логе) по отдельной кнопке, там же коэффициенты для линии тренда и погрешности для них.
